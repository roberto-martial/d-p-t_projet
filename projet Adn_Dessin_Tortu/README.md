# **Projet : Visualisation d'ADN avec Turtle en Python**  

---

## **Description**  

Ce projet vise à **analyser une chaîne d'ADN** puis à **dessiner une représentation graphique** de cette chaîne sous forme de cases grâce à la bibliothèque `turtle` en Python.  

L'objectif est de relier les bases de l'ADN (A, T, C, G) à des motifs géométriques simples et d'afficher l'ADN de manière intuitive et artistique.

## **Objectifs**  

1. **Analyse de l'ADN** :  
   - Lire une chaîne d'ADN composée des bases **A, T, C, G**.  
   - Traduire chaque base en une **forme géométrique** (ex. carré, cercle, triangle, losange).  

2. **Dessin avec Turtle** :  
   - Utiliser la bibliothèque `turtle` pour dessiner les motifs.  
   - Aligner les formes de manière ordonnée pour représenter la séquence ADN.
